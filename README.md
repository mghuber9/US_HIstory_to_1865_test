# HIST 1301 Unit 1 Study System

Static GitHub Pages site covering all eight Unit 1 sections. Open `index.html` or publish the folder contents at the repository root. No build step, account, database, server, or external service is required.

Unit 1 progress is stored only in the current browser using `localStorage` (`hist1301.studyProgress.v1`). This includes graded question history and recent 20-question practice-test attempts. Progress can be reset from **Progress options** on the Unit 1 home page.

See `CHANGELOG.md` for the August 2026 Learn/Test/tracking upgrade details.
